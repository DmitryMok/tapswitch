# Расширение «Tapswitch — вкладки»

Позволяет привязывать к кнопкам панели вкладки браузера. Подходит для любого браузера на Chromium 116+: Chrome, Opera, Comet, Edge, Brave, Vivaldi.

## Установка (один раз в каждом браузере и профиле)

1. Распаковать папку `browser_extension` из архива в постоянное место, например `C:\Users\<пользователь>\AppData\Local\Tapswitch\browser_extension`. Браузер загружает расширение из этой папки при каждом запуске: удалять или переносить её после установки нельзя. Если перенесли — загрузить заново.
2. Открыть страницу расширений:
   - Chrome — `chrome://extensions`
   - Opera — `opera://extensions`
   - Comet — `comet://extensions` (или `chrome://extensions`)
   - Edge — `edge://extensions`
3. Включить «Режим разработчика» (Developer mode).
4. «Загрузить распакованное» (Load unpacked) → выбрать папку `browser_extension`.
5. Убедиться, что расширение «Tapswitch — вкладки» включено.
6. Закрепить расширение на панели браузера (в списке расширений — «Закрепить»), иначе значок с бейджем не виден.

ID расширения во всех браузерах одинаковый — `adfbcjbmjkgmibjeolcjgclchfjngdkk` (задан ключом в `manifest.json`); приложение принимает подключения только от него.

## Подключение к приложению

- Приложение должно быть запущено. Расширение само подключается к `ws://127.0.0.1:3001/tabs` и присылает список вкладок при каждом изменении.
- Если приложение не запущено или перезапускается, расширение пробует снова: сразу после разрыва — каждые 3 секунды, а если браузер усыпил service worker — раз в 30 секунд.
- После установки расширения приложение перезапускать не нужно: оно подключится само в течение нескольких секунд.
- Приватные (инкогнито) окна приложению не передаются.
- Порт меняется в двух местах: `PORT` в `background.js` и `browser.port` в `%APPDATA%\Tapswitch\config.yaml`. После правки `background.js` — кнопка «Обновить» на странице расширений.
- Уже привязанную кнопку к окну браузера нужно переназначить: старая привязка останется привязкой к окну, а не к вкладке.

## Как понять, что подключилось

На иконке расширения — бейдж состояния:

- зелёная галочка `✓` — приложение подключено;
- красный крест `✕` — подключения нет.

Чтобы видеть значок, расширение должно быть закреплено на панели браузера (в списке расширений — «Закрепить»). Без закрепления бейдж не виден.

В шапке страницы управления, слева от состояния телефона, есть значок браузера: серый — расширение не подключено, зелёный — подключено. При наведении показывается подсказка, а после подключения — список браузеров.

Более подробный способ — журнал приложения (Rust-версия):

1. Открыть страницу управления: `http://127.0.0.1:3000/` (порт по умолчанию).
2. «Дополнительно» → вкладка «Журнал».
3. При подключении появится строка `Расширение подключено: Chrome` (вместо Chrome — имя браузера), при закрытии браузера или приложения — `Расширение отключилось: Chrome`.

В Rust-версии журнал также пишется в файл:

- `%APPDATA%\Tapswitch\tapswitch.log` — обычный запуск;
- `app/data/tapswitch.log` — режим разработки из папки проекта.

Файл ограничен 50 МБ: при превышении он становится `tapswitch.old.log` (прежний старый заменяется), запись продолжается в новый.

Проверка в браузере, если журнал недоступен:

1. `chrome://extensions` → «Tapswitch — вкладки» → «Service worker».
2. В консоли service worker выполнить `socket?.readyState`: `1` — соединение открыто, `0` — подключается, `3` — закрыто. Можно также открыть вкладку Network и найти WebSocket `tabs` со статусом `101 Switching Protocols`.

## Если не подключается

- Приложение не запущено — запустить и проверить журнал ещё раз.
- Порт 3001 занят другой программой — в журнале будет `Вкладки браузера недоступны: порт 3001`.
- Расширение выключено или не загружено — проверить `chrome://extensions`.
- Открыт другой браузер или другой профиль — расширение ставится в каждый отдельно.
- Порт в `background.js` не совпадает с `browser.port` — привести к одному значению и нажать «Обновить».

## Как работает

- Расширение присылает приложению список окон и вкладок при каждом изменении.
- При нажатии кнопки приложение просит расширение сделать нужную вкладку активной; окно браузера на передний план выводит сама программа.
